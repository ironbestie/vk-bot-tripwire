# vk-bot-tripwire — Автоматизация продаж через VK Клипы

**Готовое решение для блогеров, экспертов и ИП** — превращает просмотры Клипов в клиентов автоматически. Пользователь пишет кодовое слово в комментариях → бот сам квалифицирует, проверяет подписку и выдаёт лид-магнит или продаёт.

## ✨ Возможности

- 🎬 **Реакция на комментарии к VK Клипам** (через Callback API)
- 💬 **Обработка сообщений в личку сообщества**
- 🔑 **Кодовые слова-триггеры** в комментариях («гайд», «разбор», «хочу»)
- ✅ **Автоматическая проверка подписки** на сообщество
- 🎁 **Умная логика выдачи лид-магнита**:
  - Подписан → сразу получает материал
  - Не подписан → получает кнопку «Подписался(ась)»
- 🎨 **Inline-кнопки** с callback-обработкой
- 📊 **Подробное логирование** всех событий в `vk_log.txt`
- 🚀 **Работает на обычном хостинге** (не нужен VPS!)

## 📋 Требования

- **Хостинг** с поддержкой PHP 7.4+ и cURL
- **Домен** с настроенным HTTPS (обязательно для VK Callback API)
- **Сообщество VK** с правами администратора
- **Токен сообщества** с правами: `messages`, `wall`, `video`, `manage`

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/ваш-логин/vk-autofunnel.git
cd vk-autofunnel


Как пользоваться кодом?
- Сначала настраиваем виртуальный хостинг и домен.
- Размещаем файл vk_webhook.php на хостинге и копируем ссылку.
- Затем настраиваем сообщество ВК, а именно Callback API, ID сообщества и уникальный код.
- Затем подтверждаем сервер через уникальный код.
- Далее выкладываем ролик в VK клипы и пишем кодовое слово "разбор".
- Автоворонка пришлет сообщение пользователю с предложением подписаться и получить гайд в подарок за подписку.

Плюсы решения:
- Не требуется настройка виртуального окружения
- Не нужна аренда виртуального сервера (VPS), что экономит расходы
- Не требуется подписка на сторонние сервисы по типу ManyChat, решение обходится в копейки и не зависит от сторонних программ

Что можно добавить дальше
Когда эта схема заработает идеально, можно улучшить:
База данных (MySQL) — сохранять всех, кто получил гайд, чтобы не отправлять повторно
Разные лид-магниты — разные кодовые слова для разных материалов
Автопрогрев — через день после получения гайда бот сам пишет с дополнительным предложением
Передача менеджеру — "тёплых" лидов автоматически отправлять в CRM

Сценарий А: Пользователь УЖЕ подписан
Пишет комментарий с кодовым словом под Клипом
Бот сразу проверяет подписку → видит, что подписан
Сразу отправляет гайд без лишних шагов
В логах: КОММЕНТАРИЙ: user_id=123, подписан=ДА
Сценарий Б: Пользователь НЕ подписан
Пишет комментарий с кодовым словом под Клипом
Бот проверяет подписку → видит, что не подписан
Отправляет сообщение с просьбой подписаться + кнопка "✅ Подписался(ась)"
Пользователь подписывается и нажимает кнопку
Бот проверяет подписку ещё раз → отправляет гайд
В логах: КОММЕНТАРИЙ: user_id=123, подписан=НЕТ
